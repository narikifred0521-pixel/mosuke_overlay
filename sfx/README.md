# 効果音について

このフォルダには2種類ある。

- `*.mp3` … [効果音ラボ](https://soundeffect-lab.info/) の素材（本番で鳴る音）
- `*.wav` … `make_sfx.py` で合成したもの（mp3が無いときの予備）

オーバーレイは **mp3があればmp3を、無ければwavを** 鳴らす。

## 効果音の出典

効果音: [効果音ラボ](https://soundeffect-lab.info/)

同サイトの規約では素材そのものの再配布が禁止されている。ここに置いているのは本大会の配信オーバーレイで再生するためで、素材配布を目的としたものではない。
問題がある場合は `git rm --cached sfx/*.mp3` で公開から外し、配信PCにローカルで置く運用（`start_local.command`）に切り替える。

| ファイル名 | 鳴るとき | 効果音ラボの素材 |
| --- | --- | --- |
| throw_clear | 1投クリア | 剣で斬る1 |
| throw_miss | 1投ミス | 刀の素振り（ピュッ） |
| start | FINALスタート | （合成音） |
| tick / tick_last | 残り10秒のカウント | （合成音） |
