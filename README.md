# MöSUKE 配信オーバーレイ（試作）

MöSUKE（全14種目・ステージ突破方式）のライブ配信用オーバーレイ。もるまさスコアと同じく「操作パネル → オーバーレイ」の2画面構成。

| ファイル | 用途 |
| --- | --- |
| `overlay.html` | ブラウザソース用（背景透過）。中身は1920×1080で作り、**画面サイズに自動で合わせて拡大縮小**する |
| `control.html` | 操作パネル（スマホ幅対応）。上部に**いま配信に出ている種目表示のライブプレビュー**（押し忘れ確認用）。OBSのカスタムドックに入れる |
| `index.html` | デモ（操作パネルとオーバーレイを並べて表示） |
| `common.js` | 種目・選手データ、状態、同期、判定ロジック |

## 表示パーツ

- 種目HUD（右下）: 種目名／クリアの段階（4m・6m・8m／左・右）／ミス／「あとN回までOK」
- 進行バー（右上）: 14種目のマス。クリア＝金、失敗＝赤、挑戦中＝点滅
- 選手ロワーサード（左下）: ゼッケン・名前・肩書き・現在の状況
- 全体ボード（右）: 全員の到達状況と残り人数（第2回は24人＝2列）
- 演出: CLEAR! ／ STAGE CLEAR ／ FAILED ／ COMPLETE!（完全制覇）／ LAST CHANCE（あと1回もミスできない状態になったとき）
- FINAL: タイムアタック50のタイマー・得点・連続ミス（50点超え→25点、3連続ミス／1分10秒超えで自動失格）

## 効果音

鳴らすのはオーバーレイ側だけ。**mp3があればmp3、無ければwav**を鳴らす（→ `sfx/README.md`）。

| ファイル | 鳴るとき |
| --- | --- |
| throw_clear | 1投クリア（毎投） |
| throw_miss | 1投ミス（毎投） |
| start | FINALスタート |
| tick / tick_last | 残り10秒のカウント |

カットイン（CLEAR!・STAGE CLEAR・FAILED・COMPLETE!・LAST CHANCE）には音を付けていない。

**鳴らす端末**は設定タブで選ぶ。スマホ1台で配信していると、スピーカーから出た効果音をマイクが拾って二重に入るので、その場合は「操作パネル」を選んで手元の端末から鳴らす。

効果音は[効果音ラボ](https://soundeffect-lab.info/)（mp3）。`*.wav` は `make_sfx.py` で合成した予備。ローカルで動かすときは `start_local.command`。

OBSではブラウザソースの音がそのまま配信に乗る（プロパティの「OBS経由で音声を制御する」で音量調整）。ブラウザで開いたときは、1回クリックするまで鳴らない。`overlay.html?mute=1` で消音。

## 設定（操作パネルの「設定」タブ）

- 種目表示の位置（右下／左上）と、画面の端からの余白（px。0にすると隅にぴったり＝配信アプリのロゴを隠せる）
- 効果音（鳴らす／消す・**鳴らす端末**（配信画面／操作パネル／両方）・音量・試聴）
- 選手名簿（1人ずつ編集、またはスプレッドシートから「番号・名前・肩書き」をまとめて貼り付け）。15人以上なら全体ボードは2列
- 種目ルール（種目名・段階・ミス可の数）
- FINAL（制限時間・目標点・超えたら戻る点・連続ミス失格の回数）
- 設定の書き出し／読み込み（配信PCへの持ち込み用）／初期値に戻す

保存するとオーバーレイは自動で読み込み直す。

## URLのオプション

| 付けるもの | 効果 |
| --- | --- |
| `?room=名前` | その名前で別端末と同期する |
| `&fit=width` | 横幅に合わせる（縦画面の配信で大きく出したいとき） |
| `&zoom=1.2` | さらに拡大・縮小（0.8で小さく） |
| `&bg=1` | 市松模様の背景つきプレビュー（**配信では付けない**） |
| `&mute=1` | 効果音を消す |
| `?only=hud` | 種目表示だけを左上に出す（操作パネルのプレビューが使っている） |

## 動画に効果音を後から入れる（スマホ配信用）

スマホ配信アプリはWebページの音を配信に混ぜられない（マイク越しにしか入らない）。
そこで、**録画に映っているオーバーレイの表示から1投ごとの判定を読み取って**、効果音を後入れする。

```bash
# Final Cut用: FCPXMLを渡すと、レーン-1に効果音を並べたFCPXMLを書き出す
python3 fcpxml_sfx.py 入力.fcpxml
python3 fcpxml_sfx.py 入力.fcpxmld --dry-run      # 検出結果だけ見る
python3 fcpxml_sfx.py 入力.fcpxml --video 別の動画.mov --csv 結果.csv

# 動画に直接混ぜたいとき
python3 video_sfx.py 録画.mov
```

- 判定の根拠は「クリアの黄色いマス」「ミスの赤い丸」が増えた瞬間。演出の帯は面積で除外している
- **記録の押し忘れは編集で直せる**：`--dry-run --csv 結果.csv` で一覧を出す → CSVに行を足す/消す → `--from-csv 結果.csv` で入れ直す
- `--offset -0.2` で全体のタイミングを前後にずらせる
- 検出の分解能は0.1秒。FCPXML側はシーケンスのフレーム間隔に丸める
- 必要: ffmpeg / ffprobe / numpy

## 同期

- 同じPC内（OBSのカスタムドック＋ブラウザソース）: BroadcastChannel + localStorage。設定不要
- スマホ・別PC: 設定タブ「スマホ同期」でルーム名を入れる。オーバーレイは `overlay.html?room=ルーム名`
  - DBはもるまさスコアと同じ Firebase Realtime DB（`mosuke_overlay/<ルーム名>/state` と `/config`）
  - Firebaseコンソールで Realtime Database のルールに以下を追加する必要がある

```json
"mosuke_overlay": {
  ".read": true,
  ".write": true
}
```

## 川西モルック検定RTA（2026-11-02追加）

MöSUKEとは別ページ。12級→1級を「12投中7本」で順に合格していくタイムアタック用。

- 操作: `kentei_control.html?room=ルーム名`（スマホ。○／✕、合格で「次へ」、不合格で「もう一度」、1つ戻す）
- オーバーレイ: `kentei.html?room=ルーム名`（左上タイマー・右上12級の進み・右下に今の級と○✕）
- 音は鳴らさない（2026-11-02 古田さん指定。ON/OFF設定も置かない）。表示の大きさは操作画面「表示」で（既定75%）、時間表示は「⏱ 時間を隠す／出す」ボタンで切り替え
- 同期は Firebase の `mosuke_overlay/<room>/kentei`。検定の中身は `kentei.js` の GRADES
- 編集用ログ: 1投ごとの時刻・○✕・合否・★見せ場・録画スタートを裏で全部残す（取り消し・リセットでも消えない。端末内＋Firebase `kentei_log`）。操作画面「記録」→「編集用CSVを保存」
- `kentei_markers.py ログ.csv 動画... -o 出力.fcpxml` で、動画の撮影時刻と突き合わせてFCPのマーカー（○✕・合格・★）付きFCPXMLを作る（時計のずれは --offset 秒）

## 第2回（2026-11-28）の準備（2026-11-09）

- 名簿の初期値を第2回の24人にした（番号＝ゼッケン＝挑戦順。名前・肩書きは出場者発表動画のテロップ表と同じ）
- 長い肩書きは「…」で切らず、文字を小さくして全部出す（最小16px）
- 3-1・3-3はミスを**左右それぞれ1回まで**数える（`perStep`）
- 端末に残っている第1回の設定・記録を読まないよう、保存の名前を v2 に変えた。第2回の端末で開けば最初から24人
- **ルーム名は第1回と別の名前にする**（例 `mosuke2`）。同じ名前だと、Firebaseに残っている第1回の名簿・記録が流れ込む
- 当日の前に：操作パネルの「全データ消去」でリハの記録を消す
